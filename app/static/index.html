Waypoint

Your maps. Each map is one building with its own floors.
How it works
  1. New map: give the building a name.
  2. Add a floor: upload the floor plan as a PDF or image, then set the scale by measuring one line you know the length of.
  3. Draw: drag boxes for rooms, bathrooms, walkways, stairs and lifts, and draw walls with the Wall tool.
  4. 3D view: see all floors stacked. Export images, a 3D model or a full backup any time.

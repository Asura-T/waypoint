# Demo data (fictional)

Everything in this folder is a **made-up demo office**, generated by `tools/make_demo.py`.
It is not a real building and contains no real addresses or equipment.

On first start, if the data directory (`/data` in Docker) is empty, Waypoint copies this
demo map into it so there is something to look at. Set `WAYPOINT_SEED_DEMO=false` to start
empty instead. Delete the demo floors under **Floors…** once you add your own.

# Demo data (fictional)

Everything in this folder is a **made-up demo office**, generated by `tools/make_demo.py`.
It is not a real building and contains no real addresses or equipment.

On first start, if there are no maps yet, Waypoint adds this as the map "Demo office (fictional)"
so there is something to look at. Set `WAYPOINT_SEED_DEMO=false` to start empty instead.
Delete it from the maps screen once you have your own maps.
